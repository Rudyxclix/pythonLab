# Experiment 10: BankAccount Class

## Aim
To create a bank account class with deposit, withdrawal, and display methods.

## Algorithm
1. Initialize the account details and starting balance in the constructor.
2. Deposit only positive amounts.
3. Withdraw only positive amounts that do not exceed the balance.
4. Display the account details and updated balance.

## Sample input
```text
500
200
```

## Sample output
```text
Deposit successful.
Withdrawal successful.
Account number: 1001
Account holder: Anu
Account type: Savings
Balance: 1300.00
```

## Explanation
The object stores account data. Its methods update the balance only when a transaction is valid.
