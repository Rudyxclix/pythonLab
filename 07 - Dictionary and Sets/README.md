# Experiment 7: Dictionaries and Sets

## Aim
To sort dictionary items, merge dictionaries, count list values, and compare sets.

## Algorithm
1. Sort a dictionary's items by key.
2. Copy one dictionary and update it with another.
3. Count each list value in a dictionary.
4. Use set intersection and difference to find common and unique values.

## Sample output
```text
Items sorted by key: [('apple', 5), ('banana', 3), ('cherry', 2)]
Merged dictionary: {'banana': 3, 'apple': 5, 'cherry': 2, 'orange': 4, 'grape': 6}
Element frequencies: {'red': 3, 'blue': 2, 'green': 1}
Common elements: [3, 4]
Unique to first set: [1, 2]
Unique to second set: [5, 6]
```

## Explanation
Dictionaries store key-value pairs, while sets provide operations such as intersection and difference.
