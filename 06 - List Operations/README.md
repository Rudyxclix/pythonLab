# Experiment 6: Lists and List Comprehensions

## Aim
To demonstrate searching, updating, adding, removing, filtering, and sorting list elements.

## Algorithm
1. Create and display a list.
2. Search for a value and update an item by its index.
3. Add and remove values with list methods.
4. Use a list comprehension to select even numbers, then sort the list.

## Sample output
```text
Original list: [12, 7, 18, 5, 10]
18 is in the list.
After updating index 1: [12, 8, 18, 5, 10]
After adding 20: [12, 8, 18, 5, 10, 20]
After removing 5: [12, 8, 18, 10, 20]
Even numbers: [12, 8, 18, 10, 20]
Sorted list: [8, 10, 12, 18, 20]
```

## Explanation
Lists are ordered and mutable. The even-number list is made with a list comprehension.
