# Experiment 3: Fibonacci Series

## Aim
To display the first `n` terms of the Fibonacci series using a loop.

## Algorithm
1. Read the number of terms and check that it is positive.
2. Start with 0 and 1.
3. Print the current term and update the two values for each repetition.

## Sample input
```text
7
```

## Sample output
```text
Fibonacci series:
0 1 1 2 3 5 8
```

## Explanation
Each term after the first two is the sum of the two preceding terms.
