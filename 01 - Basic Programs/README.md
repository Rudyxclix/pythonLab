# Experiment 1: Basic Computational Problems

## Aim
To calculate the area of a circle, check a leap year, and find the largest of three numbers.

## Algorithm
1. Read the radius and calculate `pi * radius * radius`.
2. Read a year and apply the leap-year divisibility rules.
3. Read three numbers, compare them, and display the largest.

## Sample input
```text
2
2024
10
25
15
```

## Sample output
```text
Area of the circle: 12.57
2024 is a leap year.
Largest number: 25.0
```

## Explanation
The program uses arithmetic and `if`/`elif`/`else` conditions. The area uses Python's `math.pi`.
