# Experiment 5: String Processing

## Aim
To perform common string operations using a simple menu.

## Algorithm
1. Read a string and show the operation menu.
2. Read a choice and use replacement, slicing, comparison, `count()`, or `split()` as appropriate.
3. Display the result, or report an invalid choice.

## Sample input
```text
madam
3
```

## Sample output
```text
The string is a palindrome.
```

## Explanation
The program runs one selected operation. Palindrome checking compares the string with its reversed slice.
