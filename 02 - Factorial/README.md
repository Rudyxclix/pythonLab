# Experiment 2: Factorial Using Loops

## Aim
To find the factorial of a non-negative integer using a `for` loop.

## Algorithm
1. Read an integer.
2. If it is negative, display a message.
3. Otherwise multiply the integers from 1 through the input and display the result. For zero, the loop does not run and the result remains 1.

## Sample input
```text
5
```

## Sample output
```text
Factorial: 120
```

## Explanation
The variable `factorial` stores the product as the loop visits each integer.
