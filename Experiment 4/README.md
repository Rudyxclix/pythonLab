# Experiment 4: Prime Number

## Aim
To check whether an integer is prime using a loop.

## Algorithm
1. Read an integer. Numbers below 2 are not prime.
2. Test divisors from 2 up to one less than the number.
3. If any divisor divides evenly, mark it as not prime; otherwise, it is prime.

## Sample input
```text
13
```

## Sample output
```text
13 is a prime number.
```

## Explanation
A prime number has exactly two positive factors: 1 and itself.
